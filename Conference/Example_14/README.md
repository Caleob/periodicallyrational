# Example 14: The Cursed Exam of Unearthly Statistics

## What is this app?
This is a high-energy, spooky themed review exam designed for whole-class virtual instruction. While this specific instance reviews AP and introductory statistics (sampling distributions, central limit theorem, hypothesis testing, and confidence intervals), the underlying architecture is a universal blueprint for building an interactive, gamified review tool for any grade or subject.

## How to use it in a virtual K-12 classroom
* **Interactive Screen-Share Review:** Project the questions during a live virtual class or in-person lesson. Use the prominent navigation arrows to step through each problem collaboratively.
* **On-Demand Scaffolding:** Click the "Hint" button on any question to slide out essential formulas, definitions, and conceptual reminders without revealing the solution.
* **High-Stakes Answer Reveal:** The "Reveal Answer" button triggers a theatrical skull-and-crossbones confirmation modal (*"Are you sure you want to summon the answer?"*), building suspense and giving students time to commit to their guesses.
* **Integrated Live Whiteboard:** Use the built-in HTML5 canvas drawing pad on the right half of the screen to work through calculations, draw curves, or highlight keywords. Features red and black ink, 2px to 10px line sizes, undo, and problem-synchronized clearing.
* **Adaptable to Any Topic:** Swap out the Halloween theme or the statistics question bank in your prompt to create custom review games for history, science, literature, or foreign language.
