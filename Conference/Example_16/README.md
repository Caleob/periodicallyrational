# Example 16: Rational Function Explorer

## What is this app?
An interactive algebraic graphing tool designed for Algebra II and Pre-Calculus students to master rational functions. Students analyze dynamic rational functions with up to three linear factors in the numerator and denominator, identifying key graphical features: zeros (x-intercepts), vertical asymptotes, and removable discontinuities (holes). Features real-time Cartesian coordinate rendering, instant visual plotting, and comprehensive modal scoring.

## How to use it in a virtual K-12 classroom
* **Visual Inquiry & Discovery:** Project a randomized equation on screen during live instruction. Ask students to inspect the factored polynomial form and predict where the graph will cross the x-axis, shoot towards infinity, or create a hole.
* **Interactive Feature Tagging:** Students or teachers enter candidate x-values into dedicated color-coded cards:
  * **Zeros (Numerator = 0):** Plotted as solid purple dots directly on the x-axis.
  * **Vertical Asymptotes (Denominator = 0):** Plotted as high-contrast dashed orange lines.
  * **Holes (Canceled Factors):** Plotted as hollow emerald circles along the curve.
* **Dynamic Coordinate Crosshair:** Hover over the graph canvas to inspect precise x-coordinates, helping students align their algebraic predictions with visual features.
* **Self-Contained Assessment & Feedback:** Click "Submit" to summon a detailed feedback modal. It breaks down correct identifications, missed features, and extraneous guesses, providing a percentage score and immediate conceptual reminders.
* **Infinite Practice:** Click "Next Equation" to dynamically generate new polynomial factors with randomized integers between -8 and 8, automatically including removable factor cancellations.
