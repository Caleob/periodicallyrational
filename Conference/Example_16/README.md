# Example 16: Curriculum Deep Dive Studio (Placeholder & Workshop)

## What is this app?
This placeholder slot is reserved for your next advanced secondary subject simulation. It includes an interactive Simulation Architect where teachers can blueprint interactive manipulatives for challenging high school STEM and humanities standards.

## How to use it in a virtual K-12 classroom
* **Select Your Target Standard:** Choose from math, science, social studies, or language arts standards that students typically find difficult to visualize.
* **Choose an Interactive Architecture:** Pick from kinematic manipulatives, multi-stage gated trainers, procedural area models, or radar-style gamified simulators.
* **Generate a Production-Ready Prompt:** Create a detailed, architecturally sound prompt specifying HTML5 Canvas/SVG rendering, client-side state management, and real-time student scaffolding.
* **Deploy in Minutes:** Copy the prompt into Gemini, save the generated single-file app, and drop it into this folder to complete your custom curriculum suite.
