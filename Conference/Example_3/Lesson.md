# Lesson 3: Tactile Physics & Gentle Game Loops

### 1. Describe Physical Feelings (Not Math or Physics Engines)
* You do not need to know animation code to make apps feel responsive and alive.
* Use real-world physical metaphors in your prompts: *"float gently like drifting on water"*, *"magnetic snapping"*, and *"slide apart to make room"*.

### 2. Borrow Proven Game Mechanics
* Steal familiar feedback systems your students already know (like Wordle).
* Instead of harsh "Wrong!" messages, ask for gentle visual cues: Green for cards in the correct sequence, Yellow for cards out of place.

### 3. Build the Editor Into the Tool
* Never hardcode one single list of questions or events into your prompt.
* Ask for a setup modal or "Edit List" button where you can paste any line-separated items (history events, cell division stages, story plot points).
* One well-prompted game engine becomes an infinite activity generator for any subject.
