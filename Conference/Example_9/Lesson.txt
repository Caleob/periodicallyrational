# Lesson 9: Scientific Modeling & Ambient Scaffolding

### 1. Demand Domain-Specific Typography
* Chemistry and advanced sciences have strict formatting rules that basic text boxes ignore.
* Explicitly prompt the AI for exact scientific notation: subscripts ($H_2O$), superscripts ($Fe^{3+}$), reaction arrows ($\rightarrow$), and number boxes stacked directly above atom symbols.
* Precision in your prompt ensures the tool matches real textbook rigor.

### 2. Ambient "Help Mode" (Hints Without Spoilers)
* Annoying pop-up windows block the problem and disrupt student flow.
* Ask for an ambient state change: clicking "Need Help?" tints the interface warm and illuminates step-by-step arithmetic hints right around the equation.
* It supports struggling learners without handing them the answer.
