# Example 15: Everyday Helper Studio (Placeholder & Workshop)

## What is this app?
This placeholder slot is reserved for your next custom teacher productivity helper. It includes an interactive Prompt Builder where you can draft, test, and copy a customized wish for your own weekly classroom routines.

## How to use it in a virtual K-12 classroom
* **Identify a Routine:** Select or describe a repetitive weekly task (grading feedback, sub plans, student pairing, or family communications).
* **Generate a Golden Prompt:** Click to produce a battle-tested prompt template with built-in educational guardrails (single standalone file, zero external dependencies, FERPA privacy).
* **Paste into Gemini:** Copy the generated wish directly into Gemini to watch your own custom helper come to life in minutes.
* **Save to Your Classroom Toolkit:** Save the resulting `.html` file into this folder to permanently replace this placeholder.
