# Example 15: EdTech UI Prompt Drafter

## What is this app?
This is a visual blueprint and prompt-drafting application created for teachers and educators who want to design custom classroom web tools without coding. Instead of trying to describe a complicated two-dimensional screen layout using only words, teachers drag, resize, and arrange simple colored geometric shapes (panels, buttons, pills, dials, text inputs, and media areas) on a dark canvas, add freehand pen flow arrows, and label each element's functional purpose. The app generates a clean, textless 960×600 PNG mockup image and an automatically synchronized, color-coded text prompt ready to paste straight into school-approved AI models like Gemini.

## How to use it in a virtual K-12 classroom
* **Visual Wireframing with Zero Code:** Add colored shapes to map out the interface of your dream classroom tool—such as a split-screen science lab, a vocabulary flashcard deck, or a math game board.
* **Smart Auto-Layering:** Large panels automatically stay in the background (lower z-index), ensuring small buttons, tags, or dials placed on top remain easy to click, drag, and configure.
* **Whiteboard Pen Annotations:** Click the 8px white pen tool to sketch flow arrows, drag paths, or connection lines directly on top of your shapes to show the AI how elements interact.
* **Avoid Vision AI Hallucination:** The exported reference image renders on a solid black background with completely blank shapes (no internal text). This prevents multimodal AI models from misreading mockup labels or hallucinating text.
* **Auto-Synchronized Dual Output:** As you label shapes in the sidebar, the tool writes a structured prompt pairing every color and hex code to its exact functional description. Click "Copy Clean Image" and "Copy Prompt", then paste both into Gemini to watch your app come to life in minutes.
