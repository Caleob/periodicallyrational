# Example 11: Lesson Transcript & Link Prep

## What is this app?
This is a 100% private, client-side utility that helps teachers prepare virtual class recordings and transcripts for AI summarization. It extracts and sanitizes Zoom, Microsoft Teams, and Webex `.vtt` caption files—stripping timestamps, cue IDs, and formatting tags—while automatically anonymizing student names to comply with FERPA student privacy. It also formats one-click hyperlinked recording links and passcodes ready for student announcements and learning management systems (Canvas, Google Classroom, Connexus).

## How to use it in a virtual K-12 classroom
* **100% Private & FERPA-Compliant:** Runs entirely in browser memory. No student data, transcripts, or recording details are ever transmitted to external servers or third-party APIs.
* **Completely Cleaned Transcripts for AI:** Drag and drop any `.vtt` file to instantly generate clean, continuous dialogue paragraphs. Copy the clean text in one click to paste into your preferred AI tool (ChatGPT, Claude, Gemini, Copilot, or NotebookLM) for lesson recaps.
* **Automatic Student Anonymization:** Automatically identifies the primary instructor and replaces all student names with `STUDENT:`, protecting student privacy before sending transcripts to any AI model.
* **Smart Meeting Link Parsing:** Click "Paste from Clipboard" to instantly parse recording URLs and passcodes from standard meeting invites, generating formatted rich-text links ready for student announcements or emails.
