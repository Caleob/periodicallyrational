# Lesson 2: Iterative Prompting & Local Data

### 1. Build in Versions (Start Simple)
* You do not need to design the final, perfect tool in your first prompt.
* Get to a useful tool that feels right fast, then ask for improvements.

### 2. Prompt for Cause and Effect (Not Code Words)
* Some jargon is helpful, but you can go a long way describing cause and effect in your own words.
* Be detailed, clear, and specific about what you want to see and how it should act on-screen.

### 3. Local Data Portability (Saving Without an Account)
* There is no cloud database or login—YOU need to handle saving if you don't want to start from scratch.
* Ask for an import/export set of buttons.
* Use TXT, CSV, or JSON as a way to save data between tool uses.
